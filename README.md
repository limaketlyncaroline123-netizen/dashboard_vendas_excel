#  Dashboard de Vendas Xbox

##  Sobre o projeto

Essa planilha foi criada no Excel durante uma aula, com o objetivo de praticar a organização de dados e a criação de um dashboard de vendas do Xbox.

##  Dados utilizados

Os dados utilizados na planilha foram disponibilizados pelo professor durante a aula.

##  Ferramentas utilizadas

- Microsoft Excel
- Fórmulas e cálculos
- Gráficos e indicadores
- Dashboard para visualização dos dados

##  Objetivo

Praticar os recursos do Excel e aprender a organizar e apresentar informações de vendas de forma visual e fácil de entender.
